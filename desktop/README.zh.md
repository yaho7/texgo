# Texgo 桌面版

Texgo 桌面版使用 Tauri 2、Rust 和 React，面向 Windows、macOS 和 Linux。它通过图片预处理加快 LaTeX 编译；项目内容不会上传到服务器。

## 使用流程

1. 打开或拖入 `.tex` 主文件。首页不显示侧栏或顶栏，左下角可进入独立设置页。工作区侧栏中，“打开项目”与“操作记录”同级，其后为资料库和最近项目，设置固定在底部。
2. Texgo 统一判断下一步：待审核引用优先，其次更新图片、处理问题，最后显示“项目已是最新状态”。
3. 底部 Command Bar 默认转换全部待处理图片。转换下拉菜单提供“选择图片转换…”和当前/全部图片重新转换，按 Esc 退出选择；项目已最新或存在问题时仍可从“转换…”发起手动操作；输出参数位于轻量弹层，提供平衡、高质量、小体积三个预设，手工修改后自动显示“自定义”。
4. 用覆盖式对比检查图片，原图在左、PDF 在右。存在路径变化时，更新完成后自动打开引用审核；只更新同路径 PDF 时保持工作区。
5. 在“操作记录”中点击“撤销”，恢复该次操作修改的引用和 PDF。

普通问题在图片列表和 Inspector 展示，单击问题行不会打开对话框；明确点击“修复”“定位文件”或“查看详情”后才进入处理。“忽略本次”仅影响当前 Workspace；“始终忽略”保存在项目 `.texgo/ignore.json`，重开项目后仍有效。可从“全部”或“已忽略”筛选恢复处理；恢复永久忽略会移除对应项目规则。忽略项不参与自动推荐和 Smart Convert，但可从菜单“手动转换一次”，不会取消忽略。规则损坏时阻塞写入，不会静默清空。自动刷新保留当前图片、搜索、筛选、滚动及对比模式和位置。

双击文件名、按 F2 或使用图片菜单“重命名”可编辑文件 basename，扩展名保持不变。Enter 提交，Esc 或点击外部取消；失败在输入框下提示。Texgo 同步迁移源图、托管 PDF、LaTeX 引用、管理映射和永久忽略规则，并在重新扫描后保留当前图片和对比状态。重命名进入操作记录，可整体撤销。名称冲突、外部修改、符号链接或未完成文件事务会阻止操作。

程序只推荐下一步，不限制手动转换入口。手动重新转换会重新生成 PDF，仍验证文件归属、外部编辑、符号链接、Journal 和未审核引用；存在未审核引用时会解释原因并引导审核，高级设置允许继续时才可直接转换。Smart Convert 始终仅处理 pending 图片。

项目菜单保留重新扫描、关闭当前项目、撤销和检查应用更新。切换操作记录或设置不关闭项目；关闭窗口默认在后台运行。支持 `Cmd/Ctrl+O` 打开项目、`Cmd/Ctrl+Enter` 执行推荐操作、`Cmd/Ctrl+Shift+Enter` 审核引用、`Cmd/Ctrl+R` 重新扫描、`Cmd/Ctrl+F` 或 `/` 搜索。预览中 Space 切换对比，左右键调分隔线，Shift 大步调整，0 或双击平滑复位。

设置单独打开，分为常规、图片处理、自动化、通知、快捷键和高级。语言支持简体中文与 English，保存后立即切换并在下次启动恢复。全局快捷键通过按键录制，录制期间暂停全局转换触发；保存状态和冲突在原位置反馈。动效采用统一时长和缓动，在系统“减少动态效果”设置下移除位移和缩放。

原始图片保留。输出目录默认是工作区根目录下的 `texgo-pdf/`，名称可自定义，也可使用工作区内的相对目录。保留源文件名和相对目录结构，例如 `figures/实验.png` 转换成 `texgo-pdf/figures/实验.pdf`。内容摘要只用于内部缓存，不出现在 PDF 文件名中。同路径不同扩展名发生输出冲突时会停止并提示，不会静默覆盖已有 PDF。

## 图片质量

| 参数 | 行为 |
| --- | --- |
| DPI | 72–1200；按原图物理密度降采样，不放大原图 |
| 质量百分比 | 1–100；100 使用无损图像流，较低数值控制不透明位图的 JPEG 压缩 |

透明位图保留透明通道，并使用无损图像流。SVG 优先保留矢量；带滤镜的对象可能被转换库局部栅格化。SVG 的字体外观依赖系统字体是否可用。

转换会读取 PNG 的物理尺寸标记、JPEG 的 JFIF 密度或 EXIF 分辨率，以保留自然页面尺寸；无有效密度时使用 72 PPI。无需设置参考宽度。TeX 自定义分辨率命令等特殊设置仍需人工核对。提高 DPI 数值不会增加原图细节。

支持 PNG、JPEG、WebP、TIFF、BMP、GIF 和 SVG。GIF/TIFF 等多帧或多页输入只处理解码器默认的第一帧或第一页，不生成动画。EPS/PS 暂不转换。

## 引用识别与替换

- 递归识别 `\input`、`\include` 和 `\subfile`。
- 识别 `\includegraphics`、星号形式、可选参数和 `\graphicspath`。
- 忽略注释、常见逐字环境和 `\verb` 中的示例代码。
- 多个同名文件、宏生成路径、缺失资源会标记出来，不猜测替换。
- 主文件所在目录作为项目根目录。根目录之外的 TeX 和图片不会自动处理。
- 源文件要求 UTF-8；替换只修改路径位置，保留其余文本和换行。

这不是完整的 TeX 解释器。复杂条件、局部作用域、自定义图片宏及动态搜索路径需要人工确认。桌面工作台负责图片处理；编译、SyncTeX 和自动编译由独立的自动化引擎提供。

## 引用审核与外部编辑器

后台 Watcher 只负责检测、扫描和刷新状态。Smart Convert 仅自动更新 Texgo 管理的 PDF；需要改变 `.tex` 引用路径时，生成 Pending Review 并等待用户确认。

审核计划记录每个目标文件的完整 SHA-256。点击应用后重新读取并验证完整计划；任一目标文件已变化，就在写入前停止，并提示重新扫描。重新生成的计划需要再次确认，不会静默套用旧 patch。审核期间的自动刷新不会更新旧计划的 fingerprint。

应用前请先保存其他编辑器中的未保存修改。磁盘内容未变化不代表外部编辑器没有 dirty buffer，Desktop 无法可靠检测它。

## 撤销与冲突

“操作记录”保存图片更新、引用变更和失败结果，转换参数与文件信息收纳在“详细信息”。确认“撤销”后，应用先共同验证引用与 PDF 的恢复条件，再恢复引用、移除新建 PDF 或恢复被更新 PDF 的备份。按兼容的逆序撤销；若 TeX 或输出被手动修改，应用会停止并保留恢复资料。

每批次引用备份保存在 `.texgo/reference-undo/`，图片映射与转换历史也存放在 `.texgo/`，关闭应用后仍可撤销。旧版本或 CLI 独立引用操作的 `.texgo/undo.json` 继续兼容；请保留整个目录，避免丢失恢复资料。

若批量替换中途失败，恢复记录保留；重新打开项目后可以撤销已完成部分。不要删除 `.texgo/` 后再尝试恢复。当前转换任务取消时，会先完成正在处理的那张图片，再停止后续任务。

## 编辑器与开放 API

桌面安装包已内置完整的 `texgo-engine`，安装一次即可同时获得图形界面和命令行引擎，不必再下载第二个工具包。引擎可以在桌面应用未运行时独立调用，通过版本化项目 JSON 和标准输入输出上的 JSON-RPC 2.0 完成图片处理与编译。

macOS 引擎路径为 `/Applications/Texgo.app/Contents/MacOS/texgo-engine`；Windows 位于选定安装目录下的 `texgo-engine.exe`；Debian 包安装到 `/usr/bin/texgo-engine`。AppImage 可从同一个桌面包提取引擎。除 Debian 包外，不会擅自修改系统 PATH；编辑器可直接使用完整路径。

VS Code 示例包含普通构建和后台监听任务；其他编辑器或插件可使用同样的接口。编译功能依赖本机已安装的 `latexmk` 和对应 LaTeX 引擎。图片处理不需要安装 TeX。

工作台使用自有 Tailwind CSS 控件，弹层、菜单和选择控件由 Radix 提供无障碍交互：侧栏承担项目导航，中央展示图片或操作记录，右侧 Inspector 属于当前图片，底部提供唯一推荐操作。最近打开和每个工作区的转换设置保存在本机应用存储中，不上传文件内容。

接口文档见 [api.md](../docs/api.md)，项目配置定义见 [project.schema.json](../docs/project.schema.json)，VS Code 示例见 [examples/vscode](../examples/vscode)。

## 下载与发布

支持本地类型检查、测试和构建，命令与原生依赖见[开发说明](../docs/development.md)。GitHub Actions 进一步验证 Windows x64、Linux x64、macOS Apple Silicon 和 Intel 的原生集成与安装包。

- 分支构建只上传产物；只有与项目版本完全匹配的 `v版本号` 标签才发布，附带 SHA256 校验文件。
- 稳定版本标记为 Latest；beta 为预发布，不替换稳定更新源。
- 应用更新需要显式检查、下载与安装；下载和安装都验证签名，安装与重启受项目操作锁保护。
- Windows 安装包未签名。macOS 使用发布工作流中的 Developer ID 签名和 Apple 公证配置，结果需在实际运行中核实。
- 本轮未发布版本，也未进行跨平台安装升级验收。

macOS 桌面版最低要求为 13.3；PDF 预览还需要更新到 Safari 18+ 对应的 WebKit。Windows 需要更新的 WebView2，Linux 需要更新的 WebKitGTK 4.1。旧浏览器内核可能无法预览 PDF，但不影响独立引擎转换。

详细发布说明见 [desktop-release.md](../docs/desktop-release.md)，CI 说明见 [README.md](README.md)。
